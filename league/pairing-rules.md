# Pairing Rules

What every set of pairings must satisfy, roughly in priority order. The league's [format](format.md) sets the table size and the number of games. Faction codes, types and reach are on [factions](factions.md).

1. **Factions only from the player's own list.** A player only plays factions from their own ranked list. This rule is never broken.
2. **No repeats, high picks.** A player never repeats a faction, and gets factions as close to the top of their list as possible.
3. **Even meetings.** Every pair of players meets about the same number of times. No pair sits together every game while other pairs never meet.
4. **Different seat every game.** Each player sits in a different seat in each of their games. Seat 1 is first in turn order.
5. **Different map every game.** Each player plays a different map in each of their games.
6. **Table reach at least 21.** This is the Law of Root's recommended sum for 4 players (5.2.1); see [reach](factions.md#reach).
7. **Militant and insurgent mix.** Each table has a sensible mix of militant and insurgent factions.
8. **One of each faction and one board per table.** These limits apply to each table, not to a round. Two games in the same round can use the same faction or the same board.
