# League Format

How the league is played. Pairings follow the [pairing rules](pairing-rules.md).

1. **Score is a win.** Other places earn nothing.
2. **Every table has 4 players.**
3. **Player count is ideally a multiple of 4.** Each season's roster sets it.
4. **No Advanced Setup (AdSet).** Each player ranks the factions they want, and the pairings choose from that list.
5. **Rounds are a grouping, not a time slot.** Games may be listed in rounds, but a round's games need not be played at the same time.
6. **Two games at once is allowed.** It is a scheduling detail, not something the pairings aim for.
