Inputs, selects, textareas, and selectable rows.

- **Field:** `.field` wraps a `<label>` above a 44px input (`.input` look: `line2` border, `radius-md`). Hint text is `ink2`; an error is `clay`, bold, and the input gets a 2px `clay` border via `aria-invalid="true"`.
- **Every control has a visible label** tied by `for` and `id`. A placeholder is an example, not a label.
- **Selectable rows:** `.chk` (checkbox) and `.rad` (radio) are whole-row 56px / 48px targets. The selected row (`.on`) takes a 2px `sel` border and an `ok-wash` ground. `.off` is the disabled look.
- **Focus:** the 3px `focus` ring.
