A tag is a short status label. It always carries a word: colour only supports the meaning, never carries it alone.

| Class | Meaning | Colours |
| --- | --- | --- |
| `.tag` | Neutral: Locked, Upcoming, a role | `card` ground, `line2` border |
| `.tag.ok` | Winner, valid, submitted, recorded | `ok` on `ok-wash` |
| `.tag.warn` | Pending, provisional, disputed, waitlisted | `warn` on `warn-wash` |
| `.tag.bad` | Void, error | `clay` on `clay-wash` |
| `.tag.mil` | Militant faction: a filled dot | `clay` on `clay-wash` |
| `.tag.ins` | Insurgent faction: a ring | `blue` on `blue-wash` |
| `.tag.solid` | Live or Recorded: the strong state | `forest`, white text |
| `.tag.adm` | The Admin role | `adm`, `paper` text |

Militant and insurgent differ by shape (dot or ring) as well as hue. `.reach` is the plain tabular number beside them.
Icons are the 12px stroke icons in the README's Iconography table.
